The sample team's requests and suggestions can be filed again the real way: an admin-only `refile-demo` action (scripts/refile-demo-items.mjs, dry run by default) files each open one an account opened again for a member, through the same server path an email member's own request takes (the Bridge GitHub App, a "Requested by <member> through Bridge." line), points a developer's pull request that closes it at the replacement, and closes the old one as not planned with a comment linking it. A member's GitHub write now runs through one function, `runAsMember`, for the browser proxy and this action alike.
