One filter pattern everywhere. Select gets `inlineLabel`: the filter's name inside the trigger in secondary text, then the value in default text and the chevron ("Status Waiting", "Product All products"), the trigger hugging its content and named by both ("Product: All products"). `multiple` with `values` and `onValuesChange` picks several values, the list staying open while options are ticked, and `displayValue` sums them up ("In progress", "Leo +1"). Studio's filter bars all use it at the md control height, beside the search field and the view switch: Library review (Status, Asked by, Product), Explorations and Being built (Status, Product, Person, where "Everyone" now reads "Person Everyone"), and the Family filter of Components, the team's components and the library's component pages ("Family All").
