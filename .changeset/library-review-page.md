Studio: Library review, the DS lead's one queue for library pieces (phase 1). A new page next to Changes lists every piece that would enter the library, whoever asked for it: library changes and the pieces explorations recorded, conflicts included. Two views, One by one (keys A add, K keep, the down arrow next) and List (a checkbox per row and per group, a bar that says what the selection touches before acting). Filters are checkbox lists: Status, Asked by, Product. The lead decides Add to the library, Keep in the designer's screen, or Use the existing piece when the check found a match; the decision is the exploration's own, shown on both pages. A designer reads it without buttons, on her own pieces first. The nav count moves from Changes to Library review and shows for whoever holds the review right only; Changes' Library group links to the new page.
