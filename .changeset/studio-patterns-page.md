Studio has a Patterns page, under Design system right after Components. It lists the design system's patterns (patterns/<id>.pattern.json) grouped as the Library groups them, Interactions then Actions: each row names the pattern, says what it is for and which components it uses, and opens its Library page. Whoever decides on behavior requests (a library reviewer or a design lead) also sees the changes asked on each pattern that wait for a decision, each linked to its request. Bridge's own Studio lists it while patterns/ has some; a team's Studio shows it once the team's data has patterns, the same rule as its Library, and this browser remembers the answer for the next pages.
