Patterns keep both kinds when one has no pattern yet. The Library's Patterns page keeps the Interactions and Actions headings, an empty kind showing a small Field Guide drawing and how a pattern of that kind comes to exist ("None yet. An action appears here once people do the same task the same way in at least two places, like Delete."). A member who can write also gets "Suggest an action" (or "Suggest an interaction"), which opens Studio's Suggest a pattern drawer on that kind (`?suggest=<kind>`). With no pattern at all, the page shows one empty state with the rules of both kinds under its title. The Library nav keeps both rows under Patterns, so an empty kind's row lands on its section. Studio's Patterns table keeps an empty kind's group row, with the same line in one cell across the columns.
