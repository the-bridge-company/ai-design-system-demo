Type sweep on the new scale. Secondary lines read in meta (13/18) everywhere: who and when under a row, ages, counts' companions, descriptions under titles, card meta, column labels, setting help, field counters and the Stepper's step meta. 12px stays for section labels, table heads, badges, tags and counts, keyboard keys, code values and chart ticks. Row titles in lists (home, Explorations, Library review) are UI 14 medium over their meta line instead of 16 over 12 or 14. Muted UI text (`t-ui t-muted`) and the new `t-meta` utility use meta. Every rule that sets a role size now sets the role's line height too (no more 14/21 or 12/18 from the root ratio).
